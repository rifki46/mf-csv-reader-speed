A dependency-free CSV reader that returns byte-identical results to csv-reader 1.0.0 on broken CSV, several times faster: it scans with native indexOf jumps and string slices instead of character-by-character concatenation, with a whole-line fast path for plain records.

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```
